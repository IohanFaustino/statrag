Three layers turn a book into an answer — Ingestion embeds it, Retrieval finds it, Features teach it.

Hybrid retrieval

Dense (OpenAI 3072d) + sparse BM25, fused with Reciprocal Rank Fusion, optional cross-encoder rerank.

Per-field collections

field_textbooks for sections, field_images for figures. Auto-created on first ingest.

Deep-tutor pipeline

Query planning → coverage loop → orchestrator-workers synthesis → vision-explain, with inline citations + rendered math.
