Ingestion Task · book → DB

Turns OCR'd statistics textbooks into hybrid-embedded Qdrant points — dense vectors (text-embedding-3-large) + BM25 sparse, one chunk per section.

Overview

Ingestion is a one-time Task (not a Service) that converts preprocessed markdown sources into Qdrant collections. It lives entirely in src/ingestion/ and imports only src.core. Six pipeline stages (A–F) run per chapter; preprocessing is a separate offline step that produces *_fixed.md inputs.

Pipeline

Six stages executed by src/ingestion/pipeline.py via run_chapter(). Each stage is labelled A–F in the module docstring (line 3–9).

flowchart TD SRC["Source .md per book/chapter"] --> RGX["B · Regex pass — normalize structure<br/>(regex_pass.py)"] RGX --> ENR["C · LLM enrich — synopsis + index_extended<br/>DeepSeek v4-flash default, non-thinking<br/>(llm_enrich.py)"] ENR --> BLD["D · build_documents — 1 section = 1 chunk<br/>split at 8000 tok · tiktoken cl100k_base<br/>(build_documents.py)"] BLD --> EMB["E · Dense embed — text-embedding-3-large (OpenAI)<br/>+ BM25 sparse (fastembed Qdrant/bm25)"] BLD --> CAP["E · Image caption embed<br/>OpenAI text-embedding-3-large on caption text"] EMB --> UP["E · Qdrant upsert — field_textbooks"] CAP --> UPI["E · Qdrant upsert — field_images"] UP --> REG["F · Manifest register — data/parsed/manifest.json"] UPI --> REG

Note: there is no separate "Preprocess" stage inside pipeline.py — preprocessing (e.g. kobo_preproc.py) is a one-time offline step that produces *_fixed.md before ingestion. The pipeline reads the already-preprocessed source directly. Stage A (static yaml + book.json) is handled outside run_chapter().

Per-field collections

Collection names are derived from the field key in each book's yaml (src/ingestion/books/<slug>.yaml). The naming function lives in src/core/qdrant_store.py:43-48. Collections are auto-created on first ingest (ensure_text_collection / ensure_image_collection).

Collection typeName patternContentExample (field=econometrics)
Text <field>_textbooks One point per chunk; dense (3072d) + sparse (BM25) named vectors; payload = section metadata + text econometrics_textbooks
Images <field>_images One point per figure; dense (3072d) named vector on caption text; payload = ImageMetadata fields econometrics_images
