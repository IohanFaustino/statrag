Chunking & payload

Chunk rule

  • 1 section = 1 chunk (no parent/child split). Source: src/ingestion/build_documents.py:3-5.
  • If a section exceeds 8000 tokens (TARGET_TOKENS = 8000, build_documents.py:29), it is split into N windows of 8000 tokens with 200-token overlap (OVERLAP_TOKENS = 200, build_documents.py:30).
  • Hard safety cap: 8190 tokens (HARD_MAX_TOKENS = 8190) — one below the OpenAI embedding limit of 8191. Oversize chunks are logged as errors (build_documents.py:31).
  • Token counter: tiktoken encoding cl100k_base (build_documents.py:28). Matches the text-embedding-3-large / GPT-4 family tokenizer.
