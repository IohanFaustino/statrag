Ingestion · Preprocessors Task · book → DB

12 offline book-specific scripts in src/ingestion/processed/ that produce *_fixed.md inputs before the pipeline runs.

Overview

Preprocessors are one-time offline steps — they are not part of the ingestion pipeline itself. Each script transforms a raw OCR or EPUB-converted markdown file into a clean *_fixed.md that the pipeline's regex pass can parse correctly. As noted in pipeline.py, the pipeline reads the already-preprocessed source directly; there is no "Preprocess" stage inside run_chapter(). Point the book yaml's source_path to the resulting *_fixed.md.

Preprocessor registry

PreprocessorBook / source formatRole
atwan_preproc.py Atwan — Time Series Analysis with Python Cookbook Demotes all single-# headers to ## so the yaml-supplied chapter_title serves as H1; dedupes consecutive duplicate headers (page-bleed safety) without removing lines.
cerqueira_preproc.py Cerqueira & Roque — Deep Learning for Time Series Cookbook (Packt EPUB-MD) Same flat-H1 demote template as Atwan: every # → ##, chapter_title becomes H1, consecutive duplicate headers blanked in-place to preserve line ranges.
cunningham_preproc.py Cunningham — Causal Inference: The Mixtape Dedupes consecutive duplicate H1s; promotes non-chapter H1s to H2; first content occurrence of each chapter title stays as H1, later repeats (e.g. per-chapter "Conclusion") are demoted.
goodfellow_preproc.py Goodfellow et al. — Deep Learning, MIT Press 2016 (EPUB-MD, no # headers) Rewrites TOC-back link lines as proper markdown headers: two-line chapter/part anchors become single # headers; section links (N.N) become ##; subsection links (N.N.N) become ###. Line numbers preserved.
kobo_preproc.py Generic Packt/kobo EPUB-HTML pandoc exports (span-wrapped text, .pagebreak divs) Runs source through pandoc + kobo_filter.lua (unwrap koboSpan spans, emit page comments, remap header levels); then merges lone chapter-number headings with the following title and collapses blank-line runs. Output: <slug>_fixed.md.
mackay_preproc.py MacKay — Mathematical Foundations of Machine Learning Demotes all single-# headers (including # Chapter N: Title style) to ##; pipeline uses yaml-supplied chapter_title as H1. Line numbers preserved.
morgan_preproc.py Morgan et al. — Handbook of Causal Analysis Keeps # Chapter N lines as H1; merges a bare chapter-number line with the immediately following title line if needed; promotes all other # headers to ##; dedupes consecutive duplicate headers.
murphy_preproc.py Murphy — Probabilistic Machine Learning: An Introduction (EPUB-MD, no # headers) Rewrites TOC-back link lines ([**N Title**](#toc…)) as proper markdown headers: chapter links → # Chapter N Title, section links → ##, subsection links → ###. Lines preserved.
pesaran_preproc.py Pesaran — Time Series and Panel Data Econometrics, OUP 2015 (EPUB-MD) Strips link wrappers from header lines (# [N.N Title](#…) → # N.N Title) so the pipeline regex recognises the numeric prefix; also removes inline image fragments from header text. Line numbers preserved.
prado_preproc.py Lopez de Prado — Advances in Financial Machine Learning (EPUB-MD) Strips leading/trailing * italic wrappers from any header line so numeric depth patterns work at every level (#### *N.N.N.N Title* → #### N.N.N.N Title). Lines preserved.
spark_ts_preproc.py Bellouti & Boufares — Time Series Analysis with Spark (Packt EPUB-MD) Demotes every single-# header to ##; yaml-supplied chapter_title serves as H1; consecutive duplicates blanked (not removed) to preserve line numbers and yaml line ranges.
stock_watson_preproc.py Stock & Watson — MyLab Intro to Econometrics 4e (EPUB-MD) Strips inline <span> tags from header lines to expose clean # Chapter N Title and # N.N Title patterns; also strips kobo span IDs from body lines.
