Extension mode deepagents · topology C

Follows a corpus chapter's formal structure and augments each part with cross-book + Wikipedia material, producing curated to-the-point text with augmented footnotes (including formulas) — plus a self-contained styled-HTML ZIP export.

Status: ✓ implemented (2026-06-09) — 763 backend + 207 frontend tests green.

What it serves

Use when you want a structured, augmented reading of a chapter you are studying: keep the book's own order and real content, but enrich each section with what other books and Wikipedia say about the same concepts — as footnotes you can follow or skip. All formulas and source citations live in footnotes; the body stays clean prose.

Topology C: the deterministic runner (scope→resolve→clarify gate→fetch→round loop) wraps the deepagents core (analyst→polish→orchestrator→augmentor→judge). Runner owns the hard cap; deep-agent owns within-round reasoning.
