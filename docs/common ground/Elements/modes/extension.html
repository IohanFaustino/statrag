Extension mode v2 · deterministic pipeline

Produces a story timeline: one "take" per source section (author's sequence) with a collapsed curiosity box of cited expansion bullets. Every citation is copied verbatim from retrieval payloads by code — LLMs never produce source text.

What it serves

Use when you want to read a chapter as a flowing narrative enriched with curiosity bullets drawn from the wider corpus and Wikipedia. Not for a single question (use Tutor / Q&A) or a linear walkthrough (use Facilitate / Resume).

Output schema

StoryDigest
  book: str                       ← runner-stamped (authoritative)
  chapter: str                    ← honest narrowed label e.g. "ch07 · 7.4–7.5"
  takes: list[Take]
    heading: str
    story: str                    ← justified prose, KaTeX-ready
    items: list[CuriosityItem]    ← may be []
      subject: str
      body: str                   ← from evidence only; no citation text
      citations: list[StoryCitation]   ← ≥1, binder-enforced
        kind: "corpus" | "wikipedia"
        label: str                ← binder-built verbatim render string
        book_name, authors, year, chapter, section_id, pages  ← corpus fields
        title, url                ← wikipedia fields
        chunk_id: str             ← corpus provenance
  unfilled_subjects: list[str]    ← subjects with zero valid evidence

Invariant #41: every non-null StoryCitation field is copied verbatim from a retrieval payload or Wikipedia REST response — LLMs never produce citation text. Legacy ExtensionDigest retained for pre-v2 conversations.
