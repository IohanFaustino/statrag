The chat modes you can pick. Each is a registered ModeSpec with its own runner, diagram, default model, and output schema. 4 modes

All modes

ModeArchitectureOutput schemaWhat it serves
Tutorsingle-agent (tool loop)TutorAnswer / DeepTutorAnswerThe default, deepest mode. Answers a question with a multi-author, structured tutorial: TL;DR, definition, formal statement, worked example + intuition, applications, and further reading — with inline citations, figures, and rendered math.
Q&Amulti-agent (4-node graph)QAAnswerPunctual, scoped Q&A. Extracts the precise gap the question asks about (and what it assumes you already know), retrieves a small high-precision set, generates a terse grounded answer, then verifies that every claim is supported.
Facilitatemulti-agent (chapter pipeline)ChapterDigestAn ordered, didactic walkthrough of a whole chapter. Fetches the chapter's sections in the book's own order and teaches each one (verbose map, ~250-400 tokens/section), streaming each block as it finishes so you watch the chapter build top to bottom.
Resumemulti-agent (chapter pipeline)ChapterDigestAn ordered, compressed recap of a whole chapter. Same structural pipeline as Facilitate, but the map step is terse (~60-100 tokens/section) — a faithful condensed summary in reading order.

Source of truth: src/services/chat/modes.py (register_all_modes). Click a mode for its diagram, spec, and output fields.

Two families

Search modes (Tutor, Q&A) retrieve by relevance to a question. Chapter modes (Facilitate, Resume) do a structural fetch of a whole chapter and emit a ChapterDigest in the book's own section order — not a search.
