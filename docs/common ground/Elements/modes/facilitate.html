Facilitate mode story pipeline (6-node, one section per request)

Teaches exactly one section per request as a connected narrative: hook → movements → takeaway. Formal statements are reproduced verbatim then unpacked didactically. Concept anchors open a corpus + Wikipedia side-chat. Pure-code bind and statement-fidelity verify ensure citations and formal statements are never model-authored.

What it serves

Use to learn a specific section in depth — narrated as a story rather than as bullet points. One section per request; send multiple messages to walk a chapter. Pick Resume for a compressed multi-section recap, Tutor for a free-form conceptual question.

ConceptChat side panel

Clicking a concept pill in the rendered story opens the ConceptChat side panel. It hits POST /api/concept/explore (stateless — no conversation store read/write) with the concept term + provenance context. A "deepen" follow-up question is supported. Corpus + Wikipedia context is retrieved for each question.

Legacy: FacilitateDigest (pre-remake)

Conversations stored before the 2026-06-12 remake used the old chapter-loop pipeline emitting FacilitateDigest{blocks[]}. These are still rendered by FacilitateDigestCard. The frontend discriminates on schema: "FacilitateStory" → new card; "FacilitateDigest" → legacy card. No DB migration required.
