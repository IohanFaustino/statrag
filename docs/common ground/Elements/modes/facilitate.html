Facilitate mode multi-agent (chapter pipeline)

An ordered, didactic walkthrough of a whole chapter. Fetches the chapter's sections in the book's own order and teaches each one (verbose map, ~250-400 tokens/section), streaming each block as it finishes so you watch the chapter build top to bottom.

What it serves

Use to learn a chapter section by section in its intended order. Structural, not search-driven — the chapter's section order IS the answer order. Pick Resume instead when you want a compressed recap.
