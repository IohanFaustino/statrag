Facilitate mode multi-agent (6-node story pipeline)

Single-section narrative walkthrough. Resolves exactly ONE section per request, then narrates it as a connected story (hook → movements → takeaway). Formal statements (definition / theorem / proposition / lemma / corollary / remark) are reproduced VERBATIM then unpacked didactically. Concept pills open the ConceptChat side panel (/api/concept/explore) for stateless corpus + Wikipedia follow-up. Pure-code bind and statement-fidelity verify replace the old LLM ground node.

The old chapter-loop pipeline (run_chapter / ChapterDigest / CHAPTER_MAP_FACILITATE_PROMPT) is retired for facilitate as of 2026-06-12. FacilitateDigest conversations still render via the legacy card. See doc 53.

What it serves

Use to learn a single section in depth — the story arc and verbatim formal statements give you both the precise math and the narrative around it. Send another message for the next section. Pick Resume instead when you want a compressed multi-section chapter recap.
