Q&A mode storytelling (5-node flat pipeline)

Storytelling depth on one gap. Scopes the precise question, retrieves corpus and Wikipedia evidence in parallel, writes a three-act narrative (intro→deepening→conclusion) with inline citation markers, binds citations by pure code from verbatim payload, then audits grounding. Anti-tutor by construction: three fixed string fields — no sections, figures, or aspects.

What it serves

Use for a specific, bounded question where you want storytelling depth — not a full tutorial. Q&A digs into one gap with a rhetorical arc (scene-setter → core explanation → take-away) grounded in corpus sources and Wikipedia context. The verify node flags unsupported claims and reports a grounding confidence.

Output fields

FieldMeaning
intro1 paragraph — scene-setter, frames the gap.

conclusion1 paragraph — take-away; what this means for you.
scopeResolved QAScope (target_gap, assumed_known, answer_form, wiki_terms), echoed for transparency.
citationsVerbatim StoryCitation list from Evidence.meta. 📕 = corpus rows; 🌐 = wikipedia chips.

schemas/output.py. QAStoryDraft (writer intermediate) has NO citation field — model can never author citations.
