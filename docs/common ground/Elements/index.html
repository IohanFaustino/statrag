What it is

statrag is a local-first, hybrid Retrieval-Augmented Generation system over OCR-processed statistics textbooks. It combines dense vector search (OpenAI embeddings) with sparse BM25 search (Qdrant native fastembed) via Reciprocal Rank Fusion, with optional cross-encoder reranking.

Collections follow a per-field naming scheme: field_textbooks for section chunks and field_images for extracted figures. The field key comes from each book's YAML config; collections are auto-created on first ingest.

Three-layer Chinese wall

LayerFolderImport rule (verified from __init__.py)
Core src/core/ Depends on NOTHING in the repo — only third-party libs. Never imports from ingestion or services.
Tasks src/ingestion/ Imports only from src.core and third-party libs. No imports from services/. Other tasks/services never import from ingestion.
Services src/services/<name>/ Imports only from src.core. Never imports from other services or from src.ingestion. Reads ingestion artifacts (yaml, manifest.json) as filesystem only — no module import.

Wall is encoded in each __init__.py: src/core/__init__.py, src/ingestion/__init__.py, src/services/chat/__init__.py.
