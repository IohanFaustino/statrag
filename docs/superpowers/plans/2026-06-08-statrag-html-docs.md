# statRAG HTML Documentation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build robust statRAG HTML docs by extending the `docs/common ground/Elements/` set — two diagrams per mode (agentic + code call-graph) plus sources/prompts/tools tables, a new landing homepage, and a site-wide "Modern Dark / Cinema" restyle.

**Architecture:** Static HTML, no server, no framework. Shared `style.css` carries the visual system (applies to every page). A hand-authored `home.html` is the front door. The 4 mode pages are regenerated by extending the existing `modes/_generate.py` generator from hand-encoded verified-from-code facts. Verification is by opening files in Chrome (`file://`) and confirming diagrams render as SVG.

**Tech Stack:** HTML5, CSS custom properties, Google Fonts (JetBrains Mono + IBM Plex Sans), Mermaid 11 (CDN), Python 3 (generator only).

**Spec:** `docs/superpowers/specs/2026-06-08-statrag-html-docs-design.md`
